0执行摘要

结论先行：Jev 和传统 LLM 不是竞争关系，而是决策栈的两层。本报告含 24 局三配置同种子成对实测（solver-only / solver+Jev / solver+DeepSeek）：

  • Jev：平均 0.55 秒/次（批量 20+ 题）、约 $0.0007/局；平均 Ante 2.88（三臂第一）、单手分 2475、总分 15348，149 次调用 0 失败。
  • 传统 LLM（实测：DeepSeek deepseek-flash，思考型）：平均 Ante 2.75（紧追 Jev、远胜免费小模型），但代价是 6.79 秒/次（12 倍延迟）、11.6 万输出 token（思考消耗，8 局）、约 30% 调用失败回退。
  • 最优解是三层漏斗：求解器（精确）→ Jev（快判断）→ LLM（低置信兜底）。

决策层行为差异（Jev vs DeepSeek）

  • 稳定性：DeepSeek 每局 3–5 次调用失败（思考超时/JSON 异常 → 回退启发式），100 次调用约 30% 回退；Jev 149 次调用 0 失败。
  • 跳盲风格：DeepSeek 激进（1.75 次/局，曾连跳两盲直冲 Boss 必败，加护栏后收敛）；Jev 的 Noul 概率天然保守（0.38 次/局）。
  • 方差：DeepSeek 上下限更宽（ante1 ↔ ante5），Jev 更稳（ante2–4 集中）——思考型输出不确定性更高。
  • 结构化：DeepSeek 依赖 JSON 容错解析（思考内容偶发混入）；Jev 原生返回结构化答案+概率分布。

数据：本项目 logs/ab_report.md（24 局逐决策 JSONL），种子 JEVATRO1–8，红牌组白注，4x 游戏速度（三臂等速）。DeepSeek 全部经 api.deepseek.com 真实调用（deepseek-flash，thinking 默认开）。

5能力边界：各自不可替代的地方

🃏 Jev（System One）的不可替代性

  • 结构化无幻觉：只返回 choice/score/noul + 概率分布，不存在"编造一个不存在的卡牌"
  • 校准置信度：RLCD 训练，confidence 可直接做路由阈值（本项目实测可用，"0.0≈无信号"已摸清）
  • 亚秒级 + 近零成本：可铺满所有高频决策点
  • 批量隔离：20 道题一次调用并行返回，天然适合多维打分

🤖 传统 LLM 的不可替代性

  • 长链推理：跨 3 个 Ante 的经济规划、极端局面的创造性救场（旗舰级；实测 glm-4-flash 尚未展现）
  • 指令泛化：没见过的 Boss 组合/卡牌交互也能给合理建议
  • 生成能力：输出解释、写复盘报告、生成 prompt 本身
  • 战绩上限：公开 GPT-6 Astra bot 多次通关金注黑牌组（旗舰级）；实测 glm-4-flash（免费档）平均 Ante 1.88，弱于基线启发式

7结论

  1. 效果（24 局三臂实测）：Jev 平均 Ante 2.88 > DeepSeek-flash 2.75 > 启发式 2.62；Jev 单手爆发（2475）与总得分（15348）均为三臂第一，且 0 非法、0 调用失败。
  2. 效率（实测）：Jev 0.55s/次 vs DeepSeek 6.79s/次（12 倍）；DeepSeek 思考型每次吃掉 ~700 输出 token，且约 30% 调用失败回退。
  3. 各自不可替代：DeepSeek 在 JEVATRO3/8 等复杂残局反超 Jev（最深 Ante 5）——推理深度真实有效；旗舰 LLM（公开：GPT-6 bot 金注通关）上限更高。分层使用：高频判断给 Jev，低频残局给思考型 LLM。
  4. 工程结论：三臂同台数据支持原判断——能用代码算的不用模型，能用 Jev 判断的不用 LLM。无限模式支持已就绪（胜利后自动继续），待决策层推进到通关后即可产出上限对比数据。
