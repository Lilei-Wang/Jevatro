0执行摘要

结论先行：Jev 和传统 LLM 不是竞争关系，而是决策栈的两层。本报告含 24 局三配置同种子成对实测（solver-only / solver+Jev / solver+LLM）：

  • Jev：实测平均 0.55 秒/次（批量 20+ 题）、约 $0.0007/局；24 局中平均 Ante 2.88（三臂最高），最大单手分均值 2475（+68% vs 基线）。
  • 传统 LLM（实测：智谱 glm-4-flash 免费档）：平均 1.78s/次，平均 Ante 1.88（三臂最低）——小模型在这个任务上弱于 Jev；估算 旗舰级 LLM（glm-5 / GPT-6 级）上限更高但单局成本美元级（见 §4、§5）。
  • 最优解是三层漏斗：求解器（精确）→ Jev（快判断）→ LLM（低置信兜底）。本项目已跑通前两层并完成 LLM 臂实测。

决策层行为差异（Jev vs LLM）

  • 跳盲风格：LLM 明显激进（1.88 次/局 vs Jev 0.38）——glm-4-flash 曾连跳两盲直冲 Boss 必败，加了"每 ante 最多跳 1"护栏后才稳住；Jev 的 Noul 概率天然保守。
  • 购买意愿：Jev 7.0 件/局 vs LLM 3.1 件——小 LLM 对"买不买"偏保守（输出 none 频率高），Jev 的多维打分总能给出可排序的值。
  • 结构化可靠性：LLM 依赖 JSON 解析容错（偶发截断需正则抽取）；Jev 原生返回结构化答案+概率分布，零解析失败。

数据：本项目 logs/ab_report.md（24 局逐决策 JSONL），种子 JEVATRO1–8，红牌组白注，4x 游戏速度（对三臂等速）。LLM 全部经智谱 open.bigmodel.cn 真实调用。

5能力边界：各自不可替代的地方

🃏 Jev（System One）的不可替代性

  • 结构化无幻觉：只返回 choice/score/noul + 概率分布，不存在"编造一个不存在的卡牌"
  • 校准置信度：RLCD 训练，confidence 可直接做路由阈值（本项目实测可用，"0.0≈无信号"已摸清）
  • 亚秒级 + 近零成本：可铺满所有高频决策点
  • 批量隔离：20 道题一次调用并行返回，天然适合多维打分

🤖 传统 LLM 的不可替代性

  • 长链推理：跨 3 个 Ante 的经济规划、极端局面的创造性救场（旗舰级；实测 glm-4-flash 尚未展现）
  • 指令泛化：没见过的 Boss 组合/卡牌交互也能给合理建议
  • 生成能力：输出解释、写复盘报告、生成 prompt 本身
  • 战绩上限：公开 GPT-6 Astra bot 多次通关金注黑牌组（旗舰级）；实测 glm-4-flash（免费档）平均 Ante 1.88，弱于基线启发式
  • 生态开放：任意 OpenAI 兼容端点即插即用（本项目 llm_layer 一次对接即跑通）

  另: Jev 还可反向给 LLM 当守门员——LLM 决策执行前 1 题 Noul 复核"明显有害吗"，$0.0001/步的护栏

分工原则：能用代码算的不用模型，能用 Jev 判断的不用 LLM。实测数据显示 Jev 层以近零成本拿到了 +44% 总得分；剩下打不过的局面（如 JEVATRO3 反向局）正是 Tier 2 该接手的长尾。

7结论

  1. 效果（24 局三臂实测）：Jev 平均 Ante 2.88 > 启发式 2.62 > glm-4-flash 1.88；Jev 单手爆发（2475）与总得分（15348）均为三臂第一，且 24 局 0 非法动作。
  2. 经济性（实测）：Jev 0.55s/次、$0.0007/局；glm-4-flash 1.78s/次、免费但战绩垫底——免费小 LLM 难当高频决策主脑。
  3. 上限：旗舰 LLM（公开：GPT-6 bot 金注通关）上限仍高于当前 Jev 配置（白注 ante 2–5，尚未触达无限模式）；差距的本质是"推理深度"，正是三层漏斗里 Tier 2 的职责。
  4. 工程结论：三臂同台数据支持原判断——能用代码算的不用模型，能用 Jev 判断的不用 LLM。无限模式支持已就绪（胜利后自动继续并记录最深深度的代码已内置），待决策层推进到通关后即可产出上限对比数据。
